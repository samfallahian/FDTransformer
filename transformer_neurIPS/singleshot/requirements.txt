# --- torch: read this before installing -------------------------------
#
# STABLE branch, not nightly -- the nightly build used during local
# development (torch==2.12.0.dev20260312) was never a requirement of the
# code, just whatever happened to be on hand; everything this repo uses
# (torch.compile, torch.amp.autocast with bfloat16, torch.jit.trace/
# torch.jit.script) has been stable-release functionality for a long
# time. Plain `pip install torch` pulls a CPU-only build, though --
# CUDA wheels live on a version-specific index:
#
#   pip install torch --index-url https://download.pytorch.org/whl/<CUDA_TAG>
#
# where <CUDA_TAG> matches the box's CUDA driver (check with `nvidia-smi`
# for the driver's max supported CUDA version, then pick the closest
# cuXXX tag PyTorch's stable index offers -- see
# https://pytorch.org/get-started/locally/, "Stable" tab, for the current
# tag matrix; this changes over time so don't hardcode a specific cuXXX
# tag into automation without checking). bootstrap_remote.sh in this same
# directory does this detection for you.
#
# Minimum functional requirement (not exact-version-critical): torch with
# CUDA support, recent enough for `torch.compile`, `torch.amp.autocast`
# with bfloat16, and `torch.jit.trace`/`torch.jit.script` (both used by
