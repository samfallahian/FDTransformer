# --- torch: read this before installing -------------------------------
#
# The version validated this session, torch==2.12.0.dev20260312, is a
# NIGHTLY build, not a PyPI stable release. Two consequences for a rented/
# wiped H200 box:
#
#   1. It is NOT installable via a plain `pip install torch==2.12.0.dev20260312`
#      -- nightlies live on a separate index, not default PyPI:
#
#        pip install --pre torch --index-url https://download.pytorch.org/whl/nightly/<CUDA_TAG>
#
#      where <CUDA_TAG> matches the box's CUDA driver (check with
#      `nvidia-smi` for the driver's max supported CUDA version, then pick
#      the closest cuXXX tag PyTorch's nightly index offers -- see
#      https://pytorch.org/get-started/locally/ , "Preview (Nightly)" tab,
#      for the current tag matrix; this changes over time so don't
#      hardcode a specific cuXXX tag into automation without checking).
#
#   2. Nightlies are PRUNED from the index over time -- the exact
#      `2.12.0.dev20260312` build is not guaranteed to still be resolvable
#      weeks/months from now. For a box that gets wiped and re-provisioned
#      repeatedly, pin the *channel* (nightly, `--pre`) rather than the
#      exact dev date, and accept a newer nightly -- that's the "or
#      greater/similar" version of pinning torch specifically, because
#      exact-pinning a nightly is the more fragile choice here, not the
#      safer one.
#
# Minimum functional requirement (not exact-version-critical): torch with
# CUDA support, recent enough for `torch.compile`, `torch.amp.autocast`
# with bfloat16, and `torch.jit.trace`/`torch.jit.script` (both used by
# save_scripted_model() -- expect the same "not supported in Python 3.14+"
# deprecation warnings this session hit; harmless on this box if it's on
# an earlier Python, see the Python version note below).
torch>=2.11.0
